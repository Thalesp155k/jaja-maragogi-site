# Jajá Maragogi — versão atualizada

Projeto pronto para publicação na Vercel com Vite + React.

## Rodar no computador

```bash
npm install
npm run dev
```

## Publicar na Vercel

1. Envie esta pasta para um repositório no GitHub.
2. Na Vercel, escolha **Add New → Project** e importe o repositório.
3. Mantenha as configurações detectadas pelo arquivo `vercel.json`.
4. Clique em **Deploy**.

O comando de build é `npm run build` e a pasta de saída é `dist`.
